# 운전 첫걸음

처음 운전하는 사람을 위한 3D 애니메이션 강의. 장면마다 차 밖과 운전석을 직접 보면서 익힙니다.

## Chapter 1 · 주행 전 확인 사항

차에 타기 전 외부 점검부터 기둥 옆 출차, 운전석 기본 조작, 출발 직전 미러·시트 맞추기까지. 33장면.

**목차**

1. **차 밖에서 점검하기** · 공원 주차장<br>차에 타기 전, 한 바퀴 · 차 밑과 주변 살피기 · 타이어 트레드(홈) 깊이 · 타이어 공기압 · 브레이크 패드·디스크 · 보닛 열고 오일·냉각수·워셔액 · 등화장치·와이퍼·유리
2. **기둥 옆 주차와 출차** · 아파트 지하 주차장<br>기둥 옆 칸은 기둥 쪽으로 붙여서 · 주차를 마치면 사이드미러 접기 · 미러를 펴고 그냥 나가면 ‘탁’ · 미러 펴고 → 살짝 비켜서 → 충분히 나가서 회전
3. **탑승 후 기본 조작** · 운전석<br>타면 가장 먼저, 안전벨트 · 페달은 오른발 하나로 · 시동 걸기 · 핸들 잡는 법·돌리는 법 · 방향지시등(깜빡이) · 비상등(비상 점멸등) · 와이퍼와 워셔액 · 전조등 켜기
4. **기어 · 파킹 브레이크 · 오토홀드** · 운전석<br>기어 ① 기어봉(레버식) · 기어 ② 칼럼식 · 기어 ③ 다이얼식 · 전자식 파킹 브레이크 (EPB) · D로 바꾸면 알아서 풀려요 · 사이드 브레이크가 손잡이식이라면 · 오토홀드 (AUTO HOLD) · 주차할 땐 오토홀드 끄기
5. **경고등 · 미러 · 시트 맞추기** · 운전석<br>계기판 경고등 확인 · 사이드미러 맞추기 · 룸미러 맞추기 · 핸들 위치 맞추기 (틸트·텔레스코픽) · 시트 포지션 맞추기 · 출발 준비 완료!
